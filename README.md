# Controle de Viaturas AFA

Web app responsivo/PWA para cadastro de motoristas, aprovação gerencial, saída e regresso de viaturas, checklist, fotos, assinatura manuscrita, quilometragem, histórico e relatório.

## Camadas
- Frontend: HTML/CSS/JavaScript sem framework, mobile-first.
- PWA: manifest + service worker.
- Persistência DEMO: localStorage.
- Backend real: Google Apps Script.
- Banco/índice: Google Sheets.
- Documentos: Google Drive.
- Publicação do frontend: GitHub Pages.
